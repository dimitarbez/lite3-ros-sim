\section{Основни безбедни команди}

\begin{lstlisting}[language=bash,caption={Build, run и verification summary}]
# setup
make -C lite3-noetic build
make -C lite3-noetic start
make -C lite3-noetic bootstrap

# offline simulation, во два терминала
make -C lite3-noetic run-emotion-sim
make -C lite3-noetic run-emotion-chat

# optional live OpenAI simulation
make -C lite3-noetic run-emotion-sim-openai

# offline verification
make -C lite3-noetic verify-emotion
make -C lite3-noetic verify-hardware-offline

# shutdown container по завршување
make -C lite3-noetic stop
\end{lstlisting}

Physical setup/run targets намерно не се повторуваат како оперативен рецепт во
овој прилог. Нивното присуство во repository Makefile не претставува дозвола
за употреба. Пред физичка операција мора да се прочитаат тековните tickets,
hardware runbook, app-control record и сите наведени manufacturer manuals, со
fresh authorization и operator.
